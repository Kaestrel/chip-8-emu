# CHIP-8 EMULATOR
A personal project regarding the application of the CHIP-8 interpreted programming language. The project itself is an interpreter that takes ROM's designed for the CHIP-8 and runs them.

The project mainly relies on **C++** alongside:

- **doctest** for opcode tests.
- **SDL2** for graphics rendering.

The project aims to convert the technology into the modern standard of the standard CPP library.
